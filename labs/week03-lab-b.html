Word embeddings

Week 3 · Lab B

02 REPRESENT Lab B · Word embeddings Week 3 · 105 min

On Tuesday every word was a column of its own. For a document–term matrix, movie and film are as different as movie and pizza. The last part of the lecture showed another way to turn words into numbers: word embeddings, where every word is a list of numbers, learned from how the word is used in billions of sentences, so that words used in similar contexts get similar numbers.

In this lab you work with such embeddings directly. You look up which words are close to each other, do arithmetic with meanings, find out what “close” means, and finally feed embeddings to Tuesday’s classifier instead of word counts.

From the lecture to the lab

The data

The word vectors are GloVe (Pennington, Socher & Manning, 2014), trained by the Stanford NLP group on about six billion words of Wikipedia and news text. We use a small version: the 10,000 most frequent English words, with 50 numbers each. One row is one word.

Section 6 uses Tuesday’s scientific abstracts, with the same split. Part 2 returns to the New Year’s resolution tweets from week 1, this time to train a classifier on the categories the crowd workers assigned.

3 · Neighbours

To find words that are close to each other, the lecture used cosine similarity: how much two vectors point in the same direction, from −1 to 1. The code below first scales every vector to length 1 (so that frequent words with long vectors do not win everything), and then defines a small function nearest() that returns the words closest to a target. You do not need to understand the matrix arithmetic inside; use the function.

wv <- as.matrix(glove[-1])
rownames(wv) <- glove$word
wv <- wv / sqrt(rowSums(wv^2))                 # every vector gets length 1

nearest <- function(target, n = 6) {
  sims <- wv %*% target                        # cosine with every word at once
  tibble(word = rownames(wv), similarity = sims[, 1]) |>
    arrange(-similarity) |>
    head(n)
}

nearest(wv["basketball", ])
nearest(wv["netherlands", ])

4 · Arithmetic with meanings

Because words are vectors, you can add and subtract them. The lecture’s analogy() computes a − b + c and returns the nearest words (leaving out the three input words).

analogy <- function(a, b, c, n = 4) {
  target <- wv[a, ] - wv[b, ] + wv[c, ]
  nearest(target, n + 3) |>
    filter(!word %in% c(a, b, c)) |>
    head(n)
}

analogy("king", "man", "woman")
analogy("paris", "france", "netherlands")

Now back to Tuesday’s task and its workflow. Only the recipe changes, which is why only the recipe chip is green: the lecture’s recipe replaces the word counts by the average word vector of each abstract. step_word_embeddings() looks up every word and averages the vectors. The split, the model and the evaluation stay as on Tuesday.

library(tidymodels)
library(textrecipes)

science <- read_csv("science-abstracts.csv") |>
  mutate(label = factor(label))

set.seed(42)                                   # the same split as Tuesday
split <- initial_split(science, prop = .8, strata = label)
train_data <- training(split)
test_data  <- testing(split)

rec_glove <- recipe(label ~ text, data = train_data) |>
  step_tokenize(text) |>
  step_word_embeddings(text, embeddings = glove, aggregation = "mean")

glove_wf <- workflow() |>
  add_recipe(rec_glove) |>
  add_model(multinom_reg(penalty = 0.01, mixture = 1) |>
              set_engine("glmnet") |>
              set_mode("classification"))

m_glove <- fit(glove_wf, data = train_data)
