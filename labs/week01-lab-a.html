Tidy wrangling

Week 1 · Lab A

02 REPRESENT Lab A · Tidy wrangling Week 1 · 105 min

Monday’s lecture made a simple point about computational communication science: before a computer can analyse anything, a text, a post or a log file has to become a table, with one row per case and one column per variable. This first lab makes you comfortable with that kind of table in R. You learn the five functions from the tidyverse that you will use in every lab of this course, filter(), select(), mutate(), group_by() and summarize(), and the pipe |> that chains them into a pipeline. At the end you turn one of your results into a bar chart with ggplot, one layer at a time.

If you have never used R before, work through chapters 2–5 of R for Computational Social Science before the session. This lab assumes that you can open RStudio and run a line of code.

From the lecture to the lab

  • A new kind of data put a survey table next to a document–term matrix. Today is the survey side; Thursday is the text side, and the functions are the same.
  • A computational problem, stated properly asked for four lines: input, output, success criterion, failure check. Section 2 asks you to write a similar set of four (input, output, steps, check) before you write any code, and section 6 shows why the fourth one matters.
  • Where the numbers come from: every number in a dataset was produced by someone, following conventions. The missing-value codes in today’s data are such a convention, and one you have to know about.

The data

Part 1 uses the European Social Survey (ESS), round 10: 37,611 people in 22 European countries, interviewed between 2020 and 2022 (fieldwork was delayed by the pandemic). The full survey has 618 variables; we kept eight, about political news use, internet use, political interest and trust in politicians. One row is one respondent. The values are exactly as the ESS publishes them, including its codes for missing answers, which are explained in section 1.

Part 2 uses the 57 US polls on gun policy that the data site FiveThirtyEight collected after the school shooting in Parkland, Florida, in February 2018. One row is one poll: which policy it asked about, who was asked, and how much support it found overall and among Republicans and Democrats.

3 · Rows and columns: filter() and select()

filter() keeps the rows that meet a condition. select() keeps the columns you name. In both, the first argument is the data and the rest says what to do with it.

nl <- filter(ess, country == "NL")
nl

select(nl, gender, news_min)

Note the double ==: a single = gives a value to an argument, a double == asks “is this equal?”. Other comparisons are != (not equal), >, <, >= and <=. You can combine conditions with a comma, which means and.

4 · Pipes

In Exercise 1 you probably stored an in-between result and used it again in the next line. This happens so often that R has a shortcut, the pipe |>. It takes the result on its left and puts it into the first argument of the function on its right. Read it as “and then”:

ess |>
  filter(country == "NL") |>
  select(gender, news_min)

This works because every tidyverse function takes a table and returns a table. From now on we will write most code as a pipe, with one step per line.

5 · New variables: mutate()

mutate() adds a column, or changes an existing one. Here we turn the gender codes into words, which will make every table and plot easier to read.

nl <- ess |>
  filter(country == "NL") |>
  mutate(gender = ifelse(gender == 1, "male", "female"))
nl

ifelse() takes a condition, the value if it is true, and the value if it is false.

6 · Groups and summaries

group_by() splits a table into groups. summarize() then shrinks every group to a single row with the summary you ask for. n() counts the rows in a group.

nl |>
  group_by(gender) |>
  summarize(n = n(),
            mean_news = mean(news_min))

8 · A plot, layer by layer

A table with 22 rows is hard to take in at a glance, and a bar chart makes the ranking easier to see. The tidyverse makes plots with ggplot, which builds a plot from layers that you add one at a time with +. Every plot needs three things:

  • the data: a table, here countries;
  • the aesthetics, written inside aes(): which column decides what you see, for example which column goes on the x axis and which on the y axis;
  • a geom: the kind of mark that stands for one row, such as a bar, a point or a line.

Everything else (the order of the bars, the labels, the colours) is added on top of these three. We build the chart in five steps. Run each chunk and look at what has changed before you go on to the next one.

Start with the data and the aesthetics only:

# step 1: data and aesthetics
ggplot(countries, aes(x = country, y = mean_news))

R draws an empty panel. It already knows which column goes on which axis and has set the scales: country codes along the x axis, minutes along the y axis. It does not know yet what to draw on them.

For that you add a geom. geom_col() draws one bar (a column) per row, as high as the value on the y axis:

# step 2: add a geom
ggplot(countries, aes(x = country, y = mean_news)) +
  geom_col()

The + must stand at the end of a line. If you put it at the start of the next line, R treats the first line as a finished plot and then stops with the error Cannot use + with a single argument.

The bars are in alphabetical order, which tells you nothing about the countries. reorder(country, mean_news) sorts the countries by their average instead:

# step 3: sort the bars
ggplot(countries, aes(x = reorder(country, mean_news), y = mean_news)) +
  geom_col()

A ranking reads more easily from top to bottom, and labels have more room on the side. coord_flip() swaps the two axes. With two-letter country codes this is a matter of taste, but in Part 2 the policies have names such as ban-assault-weapons, which do not fit under a bar.

# step 4: turn the chart on its side
ggplot(countries, aes(x = reorder(country, mean_news), y = mean_news)) +
  geom_col() +
  coord_flip()

The last step changes how the chart looks, without changing what it shows. fill = "steelblue" gives all bars the same colour. labs() sets the axis titles, a title and a caption; note that x and y keep the names they have in aes() even after coord_flip() has moved them, so x = "" removes the title next to the country codes. theme_minimal() replaces the grey background with a plainer one (try theme_classic() or theme_bw() as well).

# step 5: colour, labels and theme
ggplot(countries, aes(x = reorder(country, mean_news), y = mean_news)) +
  geom_col(fill = "steelblue") +
  coord_flip() +
  labs(x = "", y = "Minutes of political news per day",
       title = "Political news use in 22 European countries",
       caption = "Source: European Social Survey, round 10 (2020)") +
  theme_minimal()
