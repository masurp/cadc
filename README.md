# Computational Analysis of Digital Communication

Course website for the MA course *Computational Analysis of Digital Communication* at the
Vrije Universiteit Amsterdam, 2026 edition.

**Website:** <https://masurp.github.io/cadc/>

The course covers computational methods for analysing digital communication, from counting
words and dictionaries to supervised classifiers, word embeddings and large language models.
Each teaching week has a lecture, two labs in R, and interactive explainers in the
Playground. New weeks appear here as the course runs.

This repository holds the built website only (HTML, slides, lab files). The source is kept
in a separate repository. Questions about the course go through Canvas.
